## Commands

```bash
npm start           # Web dev server at localhost:3000
npm run build       # Production web build
npm test            # Run tests (React Testing Library)
npm run tauri:dev   # Desktop dev (requires Rust/Tauri CLI)
npm run tauri:build # Desktop production build
npm run cap:sync    # Sync web build to mobile (iOS/Android)
```

Before `start`, `build`, and `tauri:*` commands, `prepare:desktop-auth` runs automatically via a pre-hook (`node scripts/generateDesktopAuthPage.js`).

## Environment Setup

Create a `.env` file at the project root with these Firebase variables:

```
REACT_APP_FIREBASE_API_KEY=
REACT_APP_FIREBASE_AUTH_DOMAIN=
REACT_APP_FIREBASE_PROJECT_ID=
REACT_APP_FIREBASE_STORAGE_BUCKET=
REACT_APP_FIREBASE_MESSAGING_SENDER_ID=
REACT_APP_FIREBASE_APP_ID=
REACT_APP_FIREBASE_MEASUREMENT_ID=
```

Optional secondary Firebase project keys (for write-only operations from other projects) can also be added — see README.md.

## Architecture

**Multi-platform React app** (Web + Desktop via Tauri + Mobile via Capacitor) serving as a personal dashboard with meditation tracking, usage analytics, music studio, light cycle management, and equity tracking.

### Firebase Layer

Three-tier abstraction in `src/components/Firebase/`:
1. `firebaseClient.js` — raw Firebase SDK initialization
2. `firebase.js` — Firebase class wrapper with auth/db methods
3. `*Service.js` files (`meditationService.js`, `usageService.js`, `equityService.js`) — domain-specific CRUD operations

The Firebase instance is provided app-wide via `FirebaseContext` (initialized in `src/index.js`).

### Authentication

`withAuthentication` HOC in `src/components/Session/` monitors `onAuthStateChanged` and exposes `{ auth, admin, user, loading }` via `AuthUserContext`. Admin status is determined by a hardcoded email whitelist inside the HOC.

Route-level auth guards in `App.js`:
- `RequireAuth` — redirects unauthenticated users to `/signin`
- `RedirectIfAuthed` — redirects already-signed-in users away from auth pages

### Routing

Routes are defined as constants in `src/constants/routes.js`. `App.js` uses React Router v6 with a `ShellLayout` providing `<Outlet />` for all routes except `/desktop-auth` (OAuth redirect handler for the desktop app, which lives outside the shell).

The Music page (`/music`) is lazy-loaded with a Suspense boundary.

### Desktop Auth Flow

`/desktop-auth` is a special route that handles the OAuth redirect for the Tauri desktop app. The page is pre-generated by `scripts/generateDesktopAuthPage.js` before builds. Firebase Hosting rewrites in `firebase.json` serve this route directly.
